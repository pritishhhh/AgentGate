# Generated evidence

- `evaluation.json`: reproducible forced-tool authorization evaluation.
- `live-model.json`: redacted events from actual configured-model smoke runs.
- `dashboard.png`, `agent-console.png`, `tool-lab.png`, `mobile.png`, `login.png`: headless-browser visual verification.
- `AgentGate-source.zip`: source-only submission archive with docs and selected verification artifacts.

JSON reports and the archive are generated locally. The archive is built from an explicit source allowlist; it excludes `data/`, `.runtime/`, `.venv/`, `.git/`, `.env`, and issued credentials. Read the methodology before making security or performance claims.
